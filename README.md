One letter settling coffee vs tea: **A — coffee**. Coffee is the louder answer in this argument — the one that shows up first, gets defended loudest, and still gets made every morning even after it lets you down. Tea is the calmer, kinder drink. Coffee is the honest one: it promises nothing except that it will be there, bitter and hot, and then it is. Running `main.ts` writes that single letter, `A`, to `/output/entry.txt` (the program harness's entry file) and prints it — one letter, no hedging.

## Run it

```sh
node main.ts
```

Requires Node.js 22 or later. The program writes exactly one character, `A`, to `/output/entry.txt` (falling back to `./output/entry.txt` when `/output` is not writable, e.g. on a local run) and prints `A` to stdout.
